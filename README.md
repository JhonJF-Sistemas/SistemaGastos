# Sistema Web de Control de Gastos

Aplicación web desarrollada con Python, Flask y SQLite.

## Funcionalidades

- Inicio de sesión.
- Registro de gastos.
- Listado de gastos.
- Reporte de gastos.
- Cálculo del total acumulado.
- Almacenamiento mediante SQLite.

## Tecnologías

- Python
- Flask
- SQLite
- HTML
- CSS

## Credenciales de demostración

## Instalación

1. Instalar Python.
2. Instalar las dependencias:

```bash
pip install -r requirements.txt
```

3. Ejecutar:

```bash
python app.py
```

4. Abrir en el navegador:

http://127.0.0.1:5000

## Capturas de pantalla

Las capturas de inicio de sesión, registro de gastos, listado y reporte se incluirán en la carpeta `capturas`.
